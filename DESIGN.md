# Design

## 1. Структуры данных и алгоритмы

### Структура проекта

- `src/core/` - основная игровая логика, чистые функции без DOM
- `src/storage/` - сохранения топ результатов в `localStorage`
- `src/ui/` - интерфейс
- `src/main.ts` - связь интерфейса и логики

### Состояние игры

```ts
type GameState = {
  settings: GameSettings;
  secret: string;
  history: HistoryEntry[];
  status: 'playing' | 'won';
  startedAt: number;
  finishedAt: number | null;
};
```

В `main.ts` хранится `GameState | null`, `null`- экран меню. Состояние не мутируется: `createGame` создаёт его, `submitGuess` возвращает новый объект и добавляет запись через `[...state.history, entry]`. Старое состояние не изменяется.

История попыток `history` - массив: так как нужен порядок попыток, массив перебирается при отрисовке, а повтор попытки проверяется через `some`. Объём данных маленький (1-20 записей), поэтому линейный поиск не будет мешать.

### `evaluateGuess(secret, guess) → { bulls, cows }`

Возвращает `{ bulls, cows }`. Оба параметра приводятся к нижнему регистру, так как для hex `a` и `A` - это одна и та же цифра.

- `bulls` - количество совпадающих позиций - символ `guess` совпадает с символом `secret` на том же индексе (`filter` с индексом).
- `cows` - количество общих цифр минус `bulls`. Общие цифры считает `filter` с `includes`. Формула будет верна, потому что цифры которые хранятся в `secret` уникальны: каждая общая цифра учитывается один раз, а bull уже входит в общие.

### `countPossibleSecrets(length, base)`

Считает число размещений без повторений P(base, length) = base! / (base − length)!.

- Реализовано через рекурсию `base * countPossibleSecrets(length - 1, base - 1)`,
- Первую цифру берет из `base`, остаётся тот же расчет, но для меньших чисел.
- Базовые случаи (`length === 0` вернет `1` - нейтральный элемент произведения, `length > base` вернет `0` - не хватает цифр),
- `memoize` хранит результаты в `Map` внутри замыкания. Ключ - пара `length,base`. Ключ из одного аргумента смешал бы разные системы счисления.

### `generateSecret(length, base, random)`

На каждом шаге берёт случайную цифру из оставшихся (с `random` задаёт индекс) и строит новый массив без этой цифры через `filter`, исходный массив не меняет. `random` передаётся параметром, поэтому в тестах результат один и тот же для одних и тех же данных.

### Типы данных

- `GameSettings` - `{ length: number; base: number }`, длина 2-6, основание 2, 8, 10 или 16.
- `HistoryEntry` - `GuessResult & { guess: string }`: результат сравнения плюс сама попытка.
- `RecordEntry` - запись рекорда: `length`, `base`, `attempts`, `timeMs`, `finishedAt`. Хранится в `localStorage` списком, отсортирован по попыткам, потом по времени.
